# Shoe Customizer Frontend

Frontend application for a custom shoe design and material management platform built with Vue.js.

## Overview

This application provides the user interface for managing shoe models, materials, patterns, and customization workflows.

The platform was developed as a real-world freelance project and communicates with the backend through a REST API architecture.

## Features

- Shoe customization interface
- Material selection and management
- Pattern management
- Product catalog browsing
- User authentication
- Administrative views
- Responsive design
- REST API integration

## Tech Stack

### Frontend

- Vue.js
- JavaScript
- Axios

## Architecture

Vue.js Frontend

↓

Django REST API

↓

PostgreSQL Database
